# Changelog

All notable public changes to GALDUR are recorded here. Detailed amendment records are
also included at the end of each methodology edition.

The project uses pre-1.0 releases while the methodology is validated through practical
deployments and community review.

## [v0.95] — 2026-09-07

- Added Loop Execution Mode (AM-1).
- Added tamper-resistant acceptance and machine pre-gates (AM-2, AM-3).
- Added longitudinal drift handling for loops (AM-4).
- Split Spec Health into five independent indicators (AM-5).
- Added record patches AM-6 and AM-7.
- Published full Czech and English methodology pages.
- Published reusable dev, ops, and loop Intent Specs, governance and Hard Locks quick
  references, and the Trace Audit template.
- Clarified the dual-license boundary: templates under MIT; methodology and
  documentation under CC BY 4.0.

## [v0.9] — 2026-07-08

- First public methodology baseline.
- Introduced seven principles, L0–L3 governance levels, eleven domains, Intent Specs,
  Hard Locks, and trace-based audit.
